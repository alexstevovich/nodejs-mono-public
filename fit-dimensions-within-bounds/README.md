# @alexstevovich/fit-dimensions-within-bounds

Scale dimensions proportionally to fit within bounds.

## API

`fitDimensionsWithinBounds(dimensions, bounds)` applies the tightest axis
scale. It supports both upscaling and downscaling.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/fit-dimensions-within-bounds
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
