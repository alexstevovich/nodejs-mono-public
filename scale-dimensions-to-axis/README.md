# @alexstevovich/scale-dimensions-to-axis

Scale dimensions proportionally to set one axis.

## API

`scaleDimensionsToAxis(dimensions, axis, target)` returns a proportionally
scaled copy whose selected zero-based axis equals `target`.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/scale-dimensions-to-axis
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
