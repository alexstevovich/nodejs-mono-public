# @alexstevovich/unicode-range

Create a string from an inclusive Unicode code-point range.

## API

`unicodeRange(start, end)` returns every code point in the inclusive range. A
reversed range returns an empty string.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/unicode-range
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
