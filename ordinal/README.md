# @alexstevovich/ordinal

Format integers with their English ordinal suffix.

```js
import ordinal from '@alexstevovich/ordinal'

ordinal(1) // "1st"
ordinal(12) // "12th"
ordinal(23) // "23rd"
ordinal(-1) // "-1st"
```

The input must be a JavaScript safe integer.

This package uses ECMAScript modules and is private until explicitly reviewed
for publication.
