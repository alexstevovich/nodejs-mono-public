# @alexstevovich/next-line-start-index

Find the start index of the next line in a string.

## API

`nextLineStartIndex(content, index)` returns the position immediately after the
next newline, or `-1` when no next line exists.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/next-line-start-index
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
