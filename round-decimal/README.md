# @alexstevovich/round-decimal

Round a finite number to a number of decimal places.

## API

`roundDecimal(value, places = 0)` supports positive places after the decimal
point and negative places before it.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/round-decimal
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
