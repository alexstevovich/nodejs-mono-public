# @alexstevovich/fsmanifest-ssh

Create a manifest for a remote directory over SSH and SFTP.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/fsmanifest-ssh
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
