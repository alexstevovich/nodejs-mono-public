# @alexstevovich/lydio-molecules

Reusable user-interface components for Lydio.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/lydio-molecules
```

## Development

```sh
npm install
npm run lint
npm run format:check

```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
