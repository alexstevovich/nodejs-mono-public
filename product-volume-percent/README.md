# @alexstevovich/product-volume-percent

Compare dimension products as a percentage.

## API

`productVolumePercent(dimensions, reference)` returns the first dimension
product as a percentage of the reference product.

## Installation

This package is private until it has been explicitly reviewed for publication.
Once published, install it with:

```sh
npm install @alexstevovich/product-volume-percent
```

## Development

```sh
npm install
npm run lint
npm run format:check

npm test
```

The package uses ECMAScript modules. Its public entry point is
`src/index.js`.
